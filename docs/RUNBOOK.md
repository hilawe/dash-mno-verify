# Deploy runbook for a private masternode channel

Use [the moderator setup and operating guide](MODERATOR_GUIDE.md) for the current copy-and-run path.
It includes the required registration-context allowlist, private configuration, public member endpoint,
and platform-specific checks. This replaces the older examples that omitted the allowlist and mixed
single-tier and two-tier startup instructions.

- Members should use [the member guide](MEMBER_GUIDE.md).
- A Linux testnet pilot on your own infrastructure is in [the Linux pilot walkthrough](LINUX_PILOT.md).
- Setup participants should read [the ceremony privacy explanation](SETUP_PRIVACY.md) and
  [the contributor guide](ceremony/CONTRIBUTOR_GUIDE.md).

This is a prototype using interim setup keys until the independent ceremony is completed. The
moderator guide identifies the remaining Telegram privacy guard, Discord exclusion limit, and
reference-only web behavior. Do not treat the availability of an adapter as a completed live-platform
acceptance test.
